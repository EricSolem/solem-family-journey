SOLEM FAMILY HISTORY WEBSITE

This is a static website designed for GitHub Pages.

Upload the contents of this folder to the root of a GitHub repository. Keep index.html at the repository root (or publish this folder as root). Then enable GitHub Pages from the main branch.

The site includes the latest narrative and family photographs, including:
- 2008 Norway return by Don and Anne
- Barbara Barnes' role connecting Eric with Krister Olsen
- 2024 search for Solemsli
- The Solemsli farmhouse and keepsake key
- Hermann Aune's Bygdefolk og Bygdeliv i Støren, Bind II
- Inherited genealogy and family-history pages
- Roger and Margaret's 1961 wedding
- Don's professional portrait and later-life photos

Research notes intentionally distinguish confirmed facts, strong inferences, and unresolved points, especially around the 1880 transatlantic liner and the possibility that Ole O. was born aboard the S/S Tasso.
